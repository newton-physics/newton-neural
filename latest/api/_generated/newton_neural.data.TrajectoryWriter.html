newton_neural.data.TrajectoryWriter#

class newton_neural.data.TrajectoryWriter(path, signals, frame_dt, *, generation=None)[source]#

Bases: object

Asynchronous background writer for sharded TrajectoryDataset directories.

Copies each shard into recycled host buffers synchronously in write() (so caller tensors can be reused immediately) and writes .npy files on a background thread pool (at most 4 shards queued). Use as a context manager; exiting flushes completed shards and writes meta.json even on exception. The writer reserves the directory with .meta.json.pending until it publishes the shard index. A process killed during recording can leave this reservation alongside any shards it wrote.

with TrajectoryWriter(path, signals, frame_dt) as writer:
    writer.write(frames, episode_start, valid)
dataset = TrajectoryDataset(path)
Parameters:

  • path (str | Path) – Output directory. Existing recordings and active writers are refused. Unrelated files are allowed.

  • signals (dict[str, SignalSpec]) – Signal specifications keyed by name.

  • frame_dt (float) – Frame duration [s].

  • generation (dict[str, Any] | None) – Optional JSON-serializable metadata stored in meta.json (writer adds complete).

write(frames, episode_start, valid, *, continues=False)[source]#

Copy tensors into host staging buffers and queue an asynchronous shard write.

Parameters:

  • frames (Frames) – All dataset signals [world_count, frame_count, *shape].

  • episode_start (Tensor) – Boolean mask [world_count, frame_count] marking episode starts.

  • valid (Tensor) – Boolean mask [world_count, frame_count] marking usable frames.

  • continues (bool) – True if these frames immediately follow the previous shard for the same worlds.

close(*, complete=True)[source]#

Flush all pending shard writes, write meta.json, and return the opened TrajectoryDataset.

Truncates the shard list before the first failed write (if any), sets generation["complete"], and re-raises the write exception if complete=True.
