newton_neural.models.FlashNeRD#

class newton_neural.models.FlashNeRD(system, *, backbone=None, contact_input=None, contact_injections=None, prediction=None, frame_dt=None, readout_hidden_dim=256)[source]#

Bases: NeRDBase

Learned forward-dynamics model family with external contact sensing and a streaming temporal backbone.

Encodes externally sensed contact signals (ContactInputProbes or ContactInputSet) and injects the contact code into FlashNeRDNetwork at the sites selected by contact_injections. Predicts either one-frame state increments (PredictionStateIncrement for SolverNeRD) or pre-contact free accelerations (PredictionFreeMotion for SolverNeRDMuJoCo).

Under torch.autocast, linear layers compute in reduced precision while feature extraction, normalization, attention scores, residual streams, outputs, and integration stay in FP32. See NeRDBase for inherited attributes.

Parameters:

  • system (SystemBase) – Simulated system specification.

  • backbone (BackboneBase | None) – Temporal trunk (defaults to BackboneFlash).

  • contact_input (ContactInputBase | None) – Optional external contact sensing and encoding configuration.

  • contact_injections (Sequence[ContactInjection | str] | None) – Network injection points (ContactInjection or strings; defaults to all three when contact_input is provided). Must be omitted when contact_input is None.

  • prediction (PredictionBase | None) – Prediction target (defaults to PredictionStateIncrement).

  • frame_dt (float | None) – Frame duration [s] (inferred during fit_normalization() if omitted).

  • readout_hidden_dim (int) – Hidden layer width of the readout MLP.
