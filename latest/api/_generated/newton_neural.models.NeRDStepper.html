newton_neural.models.NeRDStepper#

class newton_neural.models.NeRDStepper(nerd, world_count, *, precision=None, compile=None)[source]#

Bases: object

Runs compiled, no-grad single-frame inference for a fixed world_count on PyTorch tensors.

Owns per-world history buffers, applies the configured Precision (scoping CUDA’s global TF32 flag during execution and storing 16-bit linear weights on a snapshot copy for fp16/bf16), compiles via torch.compile(fullgraph=True, dynamic=False) on CUDA, and validates the first step against eager IEEE FP32. After warm-up, steps perform zero host syncs and are safe to capture inside CUDA graphs.

Note: Compiled steps specialize to input shapes, strides, and inference_mode state; warm up with the same buffer layouts used inside any CUDA graph. Construct a new stepper if nerd weights are mutated afterward.

Parameters:

  • nerd (NeRDBase) – Model to deploy.

  • world_count (int) – Fixed batch/world count.

  • precision (Precision | str | None) – Override Precision or lowercase string (defaults to nerd.precision).

  • compile (bool | None) – Enable torch.compile (defaults to True on CUDA, False on CPU). When using max_autotune, call torch.set_float32_matmul_precision("high") before the first step.
