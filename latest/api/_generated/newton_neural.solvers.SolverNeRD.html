newton_neural.solvers.SolverNeRD#

class newton_neural.solvers.SolverNeRD(model, nerd, *, articulation='*', precision=None, use_cuda_graph=True, compile=None)[source]#

Bases: SolverBase

Drop-in newton.solvers.SolverBase stepping one robot per world with an integrating neural model.

Each step reads robot joint state and controls, updates the optional contact sensor, runs the compiled NeRDStepper, writes the next joint state (preserving non-robot bodies unchanged), and refreshes body transforms with newton.eval_fk. Requires dt == nerd.frame_dt and caller-supplied contacts whenever required by the contact input or CONTACT_F.

On CUDA, caches up to 16 CUDA graphs keyed by (state_in, state_out, control, contacts, observables) object identities; reuse buffer objects across steps. Supports external wp.ScopedCapture (THREAD_LOCAL and RELAXED) after one warm-up step outside capture.

Parameters:

  • model (newton.Model) – Newton scene model (one matching robot per world).

  • nerd (NeRDBase | str | os.PathLike[str]) – Integrating NeRDBase instance or checkpoint path.

  • articulation (Pattern) – Articulation label pattern (default "*").

  • precision (Precision | str | None) – Override Precision (defaults to nerd.precision).

  • use_cuda_graph (bool) – Replay steps from CUDA graphs on CUDA devices (default True).

  • compile (bool | None) – Compile the model step via torch.compile (defaults to True on CUDA).

class Observables[source]#

Bases: Observables

Observable buffers for SolverNeRD.

contact_f stores penalty-based estimated normal wrenches at state_in: for gap < 0, F = 0.5 * (ke0 + ke1) * gap * normal [N] (no friction) plus torque about body 0’s CoM [N*m] in world frame. The magnitude follows the contact stiffness ke of the two shapes, which has no part in the dynamics the model learned, so it is not calibrated against the load. Read the estimate as an indicator of contact and for its direction. It keeps contact sensors and RL contact rewards working and is not meant for force control.

contact_row_overflow: wp.array[wp.int32] | None = None#

Dropped contact rows per world, shape (world_count + 1,) (last entry is Newton’s global world).

supports_body_pair_reduced_contacts: bool = False#

Contact rows and estimated contact forces read the gap between the two surfaces. A collision pipeline with body pair reduction stores another separation for the contacts it keeps, so a step that reads the contacts refuses reduced ones.

reset(state, world_mask=None, flags=None)[source]#

Clear the model’s history and restore joint state to Newton model defaults for masked worlds.

Follows newton.solvers.SolverMuJoCo.reset(). The history of the masked worlds is always cleared. flags selects what is restored from model.joint_q and model.joint_qd (JOINT_Q, JOINT_QD, or both if None) for every joint of the masked worlds, whose body transforms are then recomputed. flags=0 restores nothing and leaves state as authored.

To start from a custom state, call this method first, write the joint coordinates, and update body transforms with newton.eval_fk(), or use SimulationNewton.restart.

Parameters:

  • state (State) – State to reset (modified in place).

  • world_mask (wp.array[wp.bool] | None) – Optional mask (world_count + 1,) of worlds to reset, whose last entry selects Newton’s global world (all worlds if None). A model built without worlds is world 0.

  • flags (StateFlags | int | None) – Optional newton.StateFlags bitmask of the joint state to restore (all if None).
