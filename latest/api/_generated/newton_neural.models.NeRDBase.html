newton_neural.models.NeRDBase#

class newton_neural.models.NeRDBase(system, *, contact_input=None, prediction=None, frame_dt=None)[source]#

Bases: Module, Registered, ABC

Abstract base class for all neural robot dynamics model families.

Composes a system, a prediction, and an optional contact_input while centralizing signal assembly, label extraction, output normalization, recorder sources, and checkpoint serialization. Subclasses implement windowed training (forward()), streaming single-frame inference (predict()), fixed-shape history buffers (history(), reset_history()), receptive_field, fit_inputs(), and settings(). Verify streaming/window parity with newton_neural.testing.check_nerd_streaming().

Parameters:

  • system (SystemBase) – Simulated system specification.

  • contact_input (ContactInputBase | None) – Optional external contact sensing and encoding configuration.

  • prediction (PredictionBase | None) – Output prediction target (defaults to PredictionStateIncrement).

  • frame_dt (float | None) – Frame duration [s] (inferred from data in fit_normalization() if omitted).

step(frames, history)[source]#

Eager, differentiable single-frame step returning next STATE signals (for integrating predictions).

history is updated in place. To differentiate through several steps, pass a clone of it at every step ({name: value.clone() for name, value in history.items()}), since autograd needs the history that each step was computed from.

sources(simulation)[source]#

Build the SignalSource list needed to record a dataset for this model from simulation.

Captures STATE and CONTACT signals pre-step, and CONTROL and LABEL signals post-step (all cloned so subsequent steps cannot overwrite recorded buffers).
