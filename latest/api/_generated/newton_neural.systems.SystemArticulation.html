newton_neural.systems.SystemArticulation#

class newton_neural.systems.SystemArticulation(spec)[source]#

Bases: SystemBase

Generalized-coordinate articulated robot (one articulation per world, fixed or floating base).

Supports free (root only), revolute, prismatic, and fixed joints.

Signals: joint_q [joint_coord_count] [m or rad, xyzw unit quaternion for floating base] and joint_qd [joint_dof_count] [m/s or rad/s] in Newton’s layout, followed by one [actuated_count] control tensor per name in spec.control (revolute and prismatic joints only).

Robot frame: For a floating base with up = -gravity / |gravity|, origin is joint_q[0:3] and rotation is heading R_h = twist(joint_q[3:7], up). For a fixed base, features use raw joint coordinates directly while Warp sensors (robot_frame()) use the world’s root anchor transform model.joint_X_p[root_joint].

Features: Fixed base: [joint_q, joint_qd, controls]. Floating base (with base rotation R_b): [joint_q[7:], R_h^T v_base (3), R_h^T w_base (3), joint_qd[6:], R_b^T (gravity / |gravity|) (3), controls], omitting global base position and heading for horizontal translation/yaw invariance.

Increments: Fixed base: [dq, dqd]. Floating base: [R_h^T dp_base (3), R_h^T r (3), dq[7:], R_h^T dv_base (3), R_h^T dw_base (3), dqd[6:]], where r is the rotation vector of q_following * q_current^-1 [rad] and R_h is the heading at current. integrate() returns a normalized canonical quaternion (w >= 0).

Parameters:

spec (Spec) – Kinematic tree and control specification (SystemArticulation.Spec).

Raises:

ValueError – If spec has unsupported joint/control types, duplicate body or actuated-joint labels, or inconsistent topology.

Body labels and actuated-joint labels must each be unique within the articulation (fixed joints may share labels).

kinematic_model(world_count, *, device)[source]#

Build a minimal shape-free newton.Model of this articulation for standalone forward kinematics.

Running newton.eval_fk reproduces the original body poses and CoM-referenced velocities without needing the full scene. Bodies have dummy unit mass/inertia and original body_com; fixed bases sit at anchor. Compatible with bind().

Parameters:

  • world_count (int) – Number of replicated worlds.

  • device (Device | str | None | device) – Target Warp or PyTorch device.

Returns:

Finalized Newton model with one articulation labeled "robot" per world.

Return type:

Model

error(reference, other)[source]#

Compute per-coordinate absolute state errors.

For floating bases, collapses the 4D base quaternion difference into a single geodesic rotation angle in [0, pi] rad, yielding joint_q shape [..., joint_coord_count - 3]: base position (3) [m], orientation angle (1) [rad], and actuated joint coordinates [m or rad].
