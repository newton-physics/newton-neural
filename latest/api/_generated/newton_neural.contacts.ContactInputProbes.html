newton_neural.contacts.ContactInputProbes#

class newton_neural.contacts.ContactInputProbes(probes, *, ground, touch_distance=0.02)[source]#

Bases: ContactInputBase

Fixed sphere probes on robot bodies sensed analytically against a single ground plane.

Suited to known contact locations on flat ground (e.g., quadruped feet); ignores all other geometry.

Frames: ground is expressed in the robot’s anchor frame (root joint parent transform, identity for a floating base). Probe positions and velocities are expressed in the robot frame (heading frame for a floating base, anchor frame for a fixed base), keeping features invariant to horizontal translation and yaw on flat ground.

Signal: contact_probes [probe_count, 8] float32 per world:

  • [0] gap [m]: signed distance from sphere surface to ground plane (negative = penetration),

  • [1:4] sphere center position [m] in the robot frame,

  • [4:7] world velocity of the sphere center [m/s] expressed in robot-frame axes,

  • [7] touching: 1.0 if gap < touch_distance, else 0.0.

Code: Per-channel normalized features clamped to [-10, 10] and flattened to [probe_count * 8]. Has no trainable weights, so gated = False.

Parameters:

  • probes (Sequence[dict[str, Any]]) – Sequence of {"body": label, "point": [x, y, z], "radius": r} dicts (body is the leaf label; point [m] is in body frame; radius [m]).

  • ground (dict[str, Any]) – Ground plane {"normal": [x, y, z], "offset": d} in the anchor frame (unit normal pointing away from ground; plane satisfies normal . p = offset [m]).

  • touch_distance (float) – Gap threshold [m] below which touching == 1.0.

Raises:

ValueError – If probes is empty, keys are missing, or ground["normal"] is not unit length.

recomputable: ClassVar[bool] = True#

True if evaluate() can recompute signals purely from joint state (for noisy training and rollouts).

reads_contacts: ClassVar[bool] = False#

True if sensor() requires collision-detected newton.Contacts from the caller.

gated: ClassVar[bool] = False#

Hint for model families (honored by FlashNeRD) to gate the contact code starting near zero when the encoder has randomly initialized trainable weights.

classmethod from_model(model, system, *, bodies, radius=None, touch_distance=0.02, articulation='*')[source]#

Create probes on bodies matching bodies and extract the static ground plane from model.

If a matched body has exactly one collision sphere, its center and radius are copied; otherwise a probe of size radius is placed at the body origin.

Parameters:

  • model (Model) – Newton model containing the robot and exactly one static plane shape.

  • system (SystemArticulation) – Robot system specification.

  • bodies (str | Sequence[str]) – One or more fnmatch patterns matched against system.spec.body_labels.

  • radius (float | None) – Fallback probe radius [m] for matched bodies without a single collision sphere.

  • touch_distance (float) – Gap threshold [m] for touching.

  • articulation (str | list[str] | Pattern[str] | list[int]) – Label pattern of the robot’s articulation in model.

Raises:

ValueError – If any pattern matches no body, radius is missing when needed, model does not have exactly one static plane shape, or the plane lies elsewhere for the robot of one world than for that of another.
