newton_neural.backbones.BackboneBase#

class newton_neural.backbones.BackboneBase(*args, **kwargs)[source]#

Bases: Module, Part, ABC

Streaming temporal trunk mapping embedded frames to hidden states.

Subclasses implement both windowed training (forward()) and single-frame deployment (step()) using fixed-shape in-place history buffers compatible with torch.compile and CUDA graphs. Verify streaming equivalence across mid-episode resets with newton_neural.testing.check_backbone_streaming().

width: int#

Feature width of input frame embeddings and output hidden states.

receptive_field: int | None#

Number of frames (including current) visible to one hidden state, or None for unbounded/recurrent history.
