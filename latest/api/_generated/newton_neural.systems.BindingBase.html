newton_neural.systems.BindingBase#

class newton_neural.systems.BindingBase[source]#

Bases: ABC

Bridge mapping a SystemBase’s per-world signals onto a newton.Model.

Returned by SystemBase.bind(). Simulations, recorders, and live audits interact with Newton models solely through these methods. All returned tensors have shape [world_count, *shape] on the Newton model’s device.

system#

Bound system specification.

world_count#

Number of parallel worlds.

Return (low, high) sampling bounds [*shape] for each CONTROL signal (+-inf if unbounded).

place(frames, worlds)[source]#

Carry STATE signals drawn for the first world to the worlds they start.

A sampler draws the states of one world, within state_bounds(). Where the worlds of a model hold the system at different places of one scene, a binding overrides this method so that every world starts at its own place. The default returns frames as they are.

Parameters:

  • frames (Frames) – STATE signals [len(worlds), *shape].

  • worlds (Tensor) – Indices [len(worlds)] of the worlds that the rows of frames start.
