newton_neural.contacts.ContactInputSet#

class newton_neural.contacts.ContactInputSet(link_count, *, capacity=64, slot_count=16, slot_dim=64, link_embedding_dim=16)[source]#

Bases: ContactInputBase

Contact input built from arbitrary rigid contacts reported by Newton’s collision detector.

Emits one row per robot link involved in each detected contact (self-contacts emit two rows) in the robot frame (heading frame for floating bases, anchor frame for fixed bases), then pools all rows per world into a permutation-invariant code of size slot_count * slot_dim + 1.

Signals:

  • contact_rows [capacity, 14] float32 (zero-padded):

    • [0:3] contact point on the margin-expanded link surface [m],

    • [3:6] unit normal pointing from link into the other body,

    • [6:9] lever arm from link origin to contact point [m],

    • [9] signed surface gap along normal [m] (negative = penetration),

    • [10:13] relative surface velocity (link minus other body) [m/s],

    • [13] 1.0 if other body is dynamic, 0.0 if static or kinematic.

  • contact_links [capacity] int32: link index in system.spec.body_labels, or -1 for padding.

  • contact_count [] int32: number of populated rows (0 .. capacity).

Code: Flattened attention-pooled slots [slot_count * slot_dim] concatenated with log(1 + count) / log(1 + capacity). All zeros when no contacts exist. Marks gated = True because the encoder is trained end to end.

Parameters:

  • link_count (int) – Number of bodies in the robot.

  • capacity (int) – Maximum contact rows retained per world (excess rows increment overflow).

  • slot_count (int) – Number of attention pooling slots.

  • slot_dim (int) – Width of each pooling slot.

  • link_embedding_dim (int) – Width of the learned per-link embedding.

recomputable: ClassVar[bool] = False#

True if evaluate() can recompute signals purely from joint state (for noisy training and rollouts).

reads_contacts: ClassVar[bool] = True#

True if sensor() requires collision-detected newton.Contacts from the caller.

gated: ClassVar[bool] = True#

Hint for model families (honored by FlashNeRD) to gate the contact code starting near zero when the encoder has randomly initialized trainable weights.
