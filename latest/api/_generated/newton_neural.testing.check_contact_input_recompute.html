newton_neural.testing.check_contact_input_recompute#

newton_neural.testing.check_contact_input_recompute(contact_input, system, model, *, articulation='*', noise=0.1, tolerance=1e-4)[source]#

Verify that a recomputable contact input’s evaluate() matches its live Warp sensor on model.

Tests two perturbed poses for signal schema (keys, shapes, dtypes, device), agreement with sensor.update(), windowed vs. single-frame consistency, and non-aliasing across consecutive calls.

Parameters:

  • contact_input (ContactInputBase) – Recomputable contact input to validate.

  • system (SystemArticulation) – Robot system specification (not modified).

  • model (Model) – Newton model containing the robot and sensed geometry.

  • articulation (str | list[str] | Pattern[str] | list[int]) – Articulation label pattern in model.

  • noise (float) – Perturbation scale in system.increment units.

  • tolerance (float) – Max allowed absolute difference per element.
