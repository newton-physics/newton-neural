newton_neural#

Neural robot dynamics for the Newton physics engine.

newton-neural trains learned dynamics models from a reference physics solver and runs them as drop-in Newton solvers across thousands of parallel worlds.

This top-level module exports shared signal types and normalization utilities (SignalSpec, SignalRole, Frames, Normalizer, and NewtonNeuralWarning). The main workflow submodules are newton_neural.models, newton_neural.data, newton_neural.training, newton_neural.evaluation, and newton_neural.solvers.

Experimental

Experimental feature. API, behavior, defaults, and supported use cases may change without prior notice.
