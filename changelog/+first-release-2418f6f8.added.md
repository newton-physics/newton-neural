Add the first version of newton-neural, a library of neural robot dynamics for Newton, with the model interface `NeRDBase`, `FlashNeRD` as the first model family with its backbones, fixed and variable contact inputs that a model of any family may take, trajectory recording, training and evaluation for a model of any family, a `LossOneStep` that can be compiled and then checks its value against the eager one, the `SolverNeRD` solver and the `SolverNeRDMuJoCo` solver for two way coupling with MuJoCo Warp, and one set of deployment options (`precision`, `compile` and `use_cuda_graph`) wherever a model is deployed.
